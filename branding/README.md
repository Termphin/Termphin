# Branding

The Termphin logo and the store graphics built from it. The name and the logo
are covered by the [trademark policy](../TRADEMARKS.md), not by the GPL.

| File | Size | Use |
|---|---|---|
| `logo.svg` | vector | The dolphin mark. The app's own copy is `assets/logo.svg`, the source every icon is generated from. |
| `logo.png` | raster | The mark on a transparent background. |
| `termphin_icon.png` | 512 × 512 | Square icon with rounded corners. |
| `app-icon-512.png` | 512 × 512 | The store listing icon. |
| `feature-graphic-1024x500.png` | 1024 × 500 | Google Play feature graphic. |
| `github-banner.png` | 1280 × 640 | Social preview banner. |
| `developer-header.png` | 2400 × 800 | Google Play developer page header. |
